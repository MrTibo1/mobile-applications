## House manager app

### Target
Everyone who wants a simple app to keep track of common household things like chores, shopping, kitchen and storage stock and payments (who owes money)

## Roadmap

Has to have
- [x] To-do
  - [x] One time tasks
  - [ ] Assigned tasks
  - [ ] Repeating tasks
- [ ] Stock management
  - [ ] Barcode scanning
- [x] Shopping lists
  - [ ] Link to stock items
- [ ] Payment management

Nice to have
- [ ] Reminders
- [ ] Receipt scanning

### Competitors

Apps such as KitchenPal, Google Keep Notes
